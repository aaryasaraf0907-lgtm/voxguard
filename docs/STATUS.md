- **Bugs found (11-12 Nov):** (1) `class_weights` were `[0.1, 0.9]` for `[bona fide, fake]`, copied from reference code that labels bona fide = 1; the first SSL-AASIST run collapsed. Fixed in #28 (SSL) and #35 (RawNet2). The committed RawNet2 results used the inverted weights (both arms alike, so the comparison is fair); both RawNet2 arms get retrained. (2) HF XLS-R applies SpecAugment time masking by default in train mode; with it on, SSL-AASIST learned slowly. Fixed in #32. (3) SSL-AASIST codec-aug part 1 (12 Nov) diverged: train loss NaN in epoch 2, then dev EER NaN for every later epoch although train loss recovered. Cause: one non-finite fp16 forward pass wrote NaN into the AASIST BatchNorm running stats (GradScaler drops the optimizer step but not buffer updates). Fixed in #39; the run is repeated from scratch. A Kaggle CPU scan of all 76,140 codec-aug training files found no bad audio (no NaN/inf, silent, short or wrong-rate clips; peaks reach 1.0 in clean and degraded audio alike), so the trigger is most likely an fp16 overflow inside the model, which #39 handles. v2 logs `skipped_batches`; if more than ~1 % of batches are skipped, look at fp32 for XLS-R or a lower LR.
