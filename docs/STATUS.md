(3) SSL-AASIST codec-aug part 1 (12 Nov) diverged: train loss NaN in epoch 2, then dev EER NaN for every later epoch although train loss recovered. A Kaggle CPU scan of all codec-aug training files for NaN/inf, silence and clipping is running to find the trigger.
